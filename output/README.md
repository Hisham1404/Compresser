# output/

**Compressed PDFs land here** — one per input file, each under 150 KB.

Everything in this folder is generated by `./run.sh`, so it is safe to delete
at any time. Re-running overwrites files of the same name rather than piling
up copies.

A file named `something-part1.pdf`, `something-part2.pdf`, … means that
document was too long to fit in one PDF at the size limit and `--split` was
used to cut it into parts.
